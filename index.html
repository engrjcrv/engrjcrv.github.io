# Personal Drive Backup Utility This is a personal utility used by its operator to back up and recover files using rclone and Google Drive. The operator initiates transfers to a Google Drive account authorized through Google's OAuth process. The utility is intended for personal backup and recovery, not as a public file-sharing service. This website provides information about the utility and its data practices. It does not itself upload files or collect Google account credentials. ## Policies - [Privacy Policy](privacy.html) - [Terms of Service](terms.html)
